# 自我考察（遗忘曲线 · 仅已学会）

## 遗忘曲线前提

**只有 `是否学会 = ✓` 且「首次学会」有日期**，才参与遗忘曲线。

| 状态 | 首次学会 / R 列 | 遗忘曲线 | 抽题池 |
|------|-----------------|----------|--------|
| ✓ 已学会 | 有日期 | ✅ 到期复习 | 到期池 25% |
| ✗ 未学会 | **无** | ❌ | 未学会池 25% |
| 空 未测 | 无 | ❌ | 未测池 50% |

✗ 只是历史标记（考过未达标 / 同步数据），**不是**「冲刺」概念。

某池为空时，其余池按原比例分配。

**当天已经做过的题（达标或未达标）当天绝不再抽。**

**不再提问**：只有用户主动说「这题不再提问」才打钩，之后永远不抽。通过/没过都不会自动打。

## 日期怎么算

锚点 = **首次学会**（第一次打 ✓ 的日期）

| 节点 | 到期日 |
|------|--------|
| R0 | = 首次学会当天 |
| R1 | R0 日期 + 1 天 |
| … | 上一节点日期 + 间隔 |

## 命令

```bash
node .cursor/skills/spaced-review/scripts/pick-question.js
node .cursor/skills/spaced-review/scripts/mark-result.js "<id>" --score=7
node .cursor/skills/spaced-review/scripts/mark-result.js --retire "<id>"
```

## 25k 及格线（打 ✓）

数字：P0/P1 ≥ **6**；P2/P3 ≥ **5**。细则见 [scoring.md](scoring.md)。

- **必须追问**（八股 1～2 个中位数点）。第一口只答一部分 → 先追问再打分，禁止凭第一口打 ✓。
- **6 分** = 追问后关键机制能补上、无硬错误、中位数一面这题能过。不是把笔记讲全。
- 关键词对上但追问空白 / 机制说不清 → 最高 5，打 **✗**。
- 不抠冷门细节。没问到的边角不影响 ✓。

## Agent 流程

1. 抽题，只出题干，先不念答案。
2. 听完第一口：不完整或像背关键词 → **先追问 1～2 个中位数点**，再打分。禁止凭第一口打 ✓。
3. `mark-result.js` 写入分数。追问挂了 → ≤5，打 ✗。
