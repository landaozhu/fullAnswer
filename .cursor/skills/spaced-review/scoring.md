# 25k 打 ✓ 标准（中位数一面）

数字线不变：P0/P1 ≥ **6**；P2/P3 ≥ **5**。  
**6 分必须是追问之后的分。** 第一口答了一部分，不能直接打 ✓。

目标：**中位数 25k 中大厂一面能过这题**，不是把笔记背完，也不是关键词对上就算会。  
假会比不会更害人：表上 ✓、真实面试追问哑口。

凡写入 `25k考察列表` 的 ✓ / ✗（自我考察、一面模拟、公司特训、Agent 自测）都按本文件。辅导（tutor-one）不写表，口头判过关也用同一把尺。

## 打 ✓ 前必须追问

第一口不完整、像背词、或缺机制时：**先追问，再打分。**  
分不清「真会」还是「暂时没说」时，只准用追问确认，不准凭第一口放人。

八股 / 阅读：**1～2 个**中位数追问（不问冷门）。  
手写：主路径能跑后再追 **1 个**常见边界，不要把所有边界问完才给分。

追问从哪来：笔记「追问」里面试常问的那些；没有就问：为什么、机制链（谁触发谁）、和易混点差在哪、一个常见边界、项目里怎么用。

## 什么叫中位数（严一点，但别细抠）

要问：多数 25k 一面面试官会追的点。  
不要问：源码行号、冷门 API、笔记每一个小节、极端边界堆砌。漏了没问到的冷门细节，**不影响 ✓**。

## 分数（追问之后）

| 分 | 含义 | 勾 |
|----|------|----|
| **7～8** | 主干较完整，中位数追问稳，小洞无妨 | ✓ |
| **6** | 刚过中位数：第一口不完整，但追问能把**关键机制**补上，无硬错误。真实一面这题能过 | ✓ |
| **5** | 第一口有对的部分，追问补不回关键机制 / 空白 / 只会关键词。真实一面这题挂 | ✗ |
| **≤4** | 硬错误、不会、手写主路径跑不通 | ✗ |

**打 ✓ 当且仅当**：无硬错误 **且** 中位数追问能答出来。  
关键词对上、对比表背过、追问说不清机制 → 最高 **5**，打 ✗。

母题第一口过了、追问挂了 → **整题不过关**，打 ✗，不要「母题保持 ✓」。

## 手写

- **6**：主路径能跑 + 常见边界追问能讲或能改（缺一个冷门边界可以过）
- **≤4**：写不出 / 跑不通
- 提示后写对 → 最多 7；贴答案复制 → 最高 4

## 禁止

- ❌ 没追问就打 ✓（第一口不完整时）
- ❌ 追问不会 / 空白仍打 ✓
- ❌ 凭关键词、半截答案放人
- ❌ 为显得严而抠中位数面试官不会问的细节，卡住本该过的人
