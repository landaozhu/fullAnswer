# 25k 二面评分（P7/P8 视角）

及格线 **6/10**。五维各 0～2，可打 0 / 0.5 / 1 / 1.5 / 2。

## 五维

| 维 | 2 分 | 1 分 | 0 分 |
|----|------|------|------|
| **职责与边界** | STAR 清楚；能主动划清「我做 / 同事做 / 没做」 | 能讲自己做了什么，边界要追才说清 | 含糊、抢功、或答非所问 |
| **技术深度** | 能讲实现、边界 case、和业务怎么咬合 | 有手段和名词，原理/细节发虚 | 只会「用了 xx」「做了优化」 |
| **权衡与决策** | 有备选、代价、为什么当时选这个 | 能说「为什么做」，说不清「为什么不那样」 | 公司让用 / 没有决策 |
| **结果与验证** | 有 before/after、怎么测、灰度/回滚 | 有数字但说不清口径或样本 | 无数据、或数字经不起问 |
| **工程判断** | 质量、故障、协作、可复盘，像 owner | 知道要自测/CR，缺体系 | 只写代码，不管上线后 |

## 25k 锚点（不是 P7 录用线）

候选人目标是 **25k 中大厂二面能过**，不是按 P7 录用标准卡死。

| 分 | 含义 |
|----|------|
| **9～10** | 这题按 P7 深挖也站得住：决策、数据、失败、边界都清 |
| **7～8** | 扎实 25k：介绍完整，追 3 轮不崩，有数据有边界 |
| **6** | 刚及格：第一口可以不完整，但追问能把关键机制补上，细节有洞但不致命。追问空白不能打 6 |
| **4～5** | 第一口有对的部分或会背 30 秒，追问补不回来 → 这题不过 |
| **0～3** | 讲不清自己的活，或夸大后被拆穿 |

P0（必背项目题）和 P1 都是 **≥6 才打 ✓**。二面没有「了解即可」。  
追问关键点空白或说不清 → 最高 **5**，不能打 ✓。不按 P7 标准细抠所有细节。

## 手写 / 算法（各 1 题，各 0～10）

及格线同样 **6**。这是现场能写，不是背题。

| 分 | 手写 | 算法 |
|----|------|------|
| **8～10** | 边界齐（循环引用 / 并发顺序 / once），能说复杂度 | 正确实现 + 复杂度对，DP 有状态转移 |
| **6～7** | 主路径能跑，缺 1 个边界但不崩 | 能跑、结果对；复杂度说得出 |
| **4～5** | 思路对，跑不通或漏核心 API | 暴力冒充 DP、或写到一半 |
| **0～3** | 写不出 / 不愿写 | 写不出 |

提示后写对 → 最多 7。贴答案后复制 → 最高 4。

一面手写偏防抖/flatten；二面按 JSON 抽到的题判，不要主动降级成更简单的题。

## 校准例子

**选座性能（期望 7+）**

- 7：先度量（串行接口、大包）→ 并行 + 分包 + 按需 → 2s→1.3s；说明指标口径；小程序额外说 setData/主包；承认座位图 SDK 不是自己对接
- 5：只说「懒加载、分包，从 2 秒到 1.3 秒」，说不清 2s 是什么、怎么测、并行哪些接口
- 3：把 SDK 内部、转化率达标都揽到自己身上，追问即崩

**条件退（期望 7+）**

- 7：时间类型 + 审核×开售状态 + 与蓄水交叉；提到自测矩阵和浅拷贝污染 store 的复盘
- 5：能列模块名，规则讲不清，质量只说「多测了测」
- 8+：能讨论为什么不上规则引擎、前后端双校验、1.0 数据兼容

**P0 故障（期望 6～8）**

- 7：先恢复再查因；回滚/开关；同步；灰度再放量；复盘有 Action
- 4：一上来「我先本地复现查代码」
- 封顶 8：若从未当过主 R，诚实说参与环节，流程讲对即可，不必假装值过夜

## 一票限制

命中以下且**追问后仍不改口** → 职责维 0，**总分最高 5**：

- 自称座位图 SDK owner / 对接人
- 自称熟悉「浏览到支付全链路业务」或 C 端业务专家
- 自称上单 2.0 / 微前端架构负责人或拍板人（应为「参与选型评审」）
- 自称写过 eslint 自研插件实现（仅为基础配置）
- 把同事模块、未做项目讲成自己的

追问后主动收回、改回题库口径 → 不触发封顶，职责维最多 1 分。

## 打分纪律

- 按**当场口述**，不要按「他笔记里会」给同情分
- 数字口径错（把 webpack 编译时间说成页面首屏）该维最多 1 分
- 单题场只评这一题；项目场综合本场开场+追问，不把没问到的模块当已掌握
